# halo — community

Public content for the [halo](https://drayki.com/products/halo) instrument.
The plugin reads this repository directly; nothing here is code.

- `latest.json` — the newest available version. The plugin checks it once a
  day and shows a small badge when a newer build exists.
- `community.json` — the community store manifest: shared presets and packs,
  with everything a card needs to draw itself before downloading anything.
- `presets/` — shared `.halo` presets (JSON, samples embedded).
- `packs/` — shared packs: a `.zip` of `.halo` presets plus their `Samples`
  folder, installable in one click from the plugin's community page.

To share a sound, use **share** inside the plugin's community page.
